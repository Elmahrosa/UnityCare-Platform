Core platform

Modular services engineered for institutional deployment.

Backend API

FastAPI (Python) with JWT auth, RBAC middleware, rate limiting, CORS, and bcrypt password hashing.

Frontend

Next.js 15 + TypeScript + Tailwind. Responsive, RTL-ready, with English & Arabic interface.

Data Layer

PostgreSQL with Alembic migrations, Redis cache, JSONB for FHIR resources, hash-chained audit integrity.

Deployment

Dockerized microservices. Railway CI/CD. Health checks. Prometheus & Grafana monitoring.

Capabilities

Production services running today. Additional modules on the roadmap.

Identity & Access Live

JWT access & refresh tokens, RBAC, rate limiting, bcrypt hashing. Registration, login, logout, token refresh.

FHIR R4 Patient Records Live

Full CRUD for FHIR R4 Patient resources. JSONB storage. Identifier, name, telecom, address, soft-delete.

Consent Engine Live

Create, version, revoke, and audit consent directives. Purpose-based, jurisdiction-aware, hash-chain integrity.

Audit Ledger Live

Immutable SHA-256 hash chain with HMAC signing. Chain verification endpoint. Every action is logged and verifiable.

Admin API Live

User management, role assignment, audit log viewer. OpenAPI docs at api.elmahrosa.org/docs.

Arabic & English Live

Full RTL support with Arabic language interface alongside English. Built for bilingual healthcare environments.

Roadmap: Telemedicine • Pharmacy • IoT • Emergency Dispatch • National Registries — Contact us for details
