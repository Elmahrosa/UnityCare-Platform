Platform architecture

Modern stack engineered for healthcare deployments.

🔨

Backend Core

FastAPI (Python) with JWT auth, refresh tokens, RBAC middleware, rate limiting, and bcrypt password hashing.

🌐

Frontend

Next.js 15 + TypeScript + Tailwind. Responsive, RTL-ready, with dual-language English & Arabic support.

Data Layer

PostgreSQL with Alembic migrations, Redis cache, JSONB for FHIR resources, hash-chained audit integrity.

Deployment

Dockerized microservices. Railway CI/CD. Health checks. Prometheus/Grafana monitoring stubs.
